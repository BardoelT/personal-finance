                          Add job

                          Add paycheck

                          Use a dot for decimals, for example 3000.00.

                          Add account

                          Add statement

                          No earlier statement, so the account is taken to start at 0.00. Enter money that was already in the account as net deposits.

                          Use a dot for decimals, for example 12500.00. Net deposits is what you put in minus what you took out, so a withdrawal is negative. Enter the balance or the capital growth and the other is calculated. A note can be up to 2000 characters.

                          Add account

                          Add entry

                          Use a dot for decimals, for example 2500.00. The balance is the closing balance of the period. A negative balance, such as -150.25, means the account is overdrawn. A note can be up to 2000 characters.

                          Add house

                          Linked debts (optional)
                          Link existing debts, such as a mortgage or a loan. When the house is sold you choose per debt whether it was repaid or cancelled.

                          Settle linked debts

                          Repaid counts as wealth accumulation from cash, Cancelled does not.

                          Add valuation

                          Use a dot for decimals, for example 150000.00. The value is what the house is worth at the end of the period, so it cannot be negative. A note can be up to 2000 characters.

                          Add debt

                          Add statement

                          Use a dot for decimals, for example 150000.00. The balance is what you still owe at the end of the period, so it cannot be negative. A note can be up to 2000 characters.

                          Add expense

                          Use a dot for decimals, for example 4500.00. The amount must be above 0.00, and the date cannot be in the future. A note can be up to 2000 characters.
